# Vibe & Verify — תחושה ואימות
### מכונת ניתוח רעיונות עסקיים עם 5 סוכנים

---

## מה זה עושה

מכניסים בריף עסקי. המכונה מריצה חוקר + 5 סוכנים במקביל ומייצרת מצגת אסטרטגית מלאה.

```
הרעיון שלך
    ↓
מחקר רשת אמיתי
    ↓
5 סוכנים עובדים במקביל
    ↓
מצגת אסטרטגית (48 שקופיות)
```

---

## דרישות

- [Claude Code](https://claude.ai/code) מותקן
- חיבור לאינטרנט
- כ-5 דקות לריצה

---

## שימוש

**1.** הורד את הפרויקט — לחץ **Code → Download ZIP**, חלץ לתיקיה על ה-Desktop.

**2.** פתח ב-Claude Code — גרור את התיקיה לתוך Claude Code.

**3.** כתוב לקלוד קוד:
```
הרץ את המכונה עם הבריף הזה:
"הרעיון העסקי שלך כאן"
```

**4.** קבל את הקובץ — `vibe-verify-report-[תאריך].pptx` נוצר בתיקיה.
